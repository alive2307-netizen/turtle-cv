# Предсказание массы морских черепах Chelonia mydas

Учебный проект курса Data Science (Яндекс Практикум).  
Цель — разработать модель линейной регрессии для бесконтактного предсказания массы зелёных морских черепах по биометрическим данным, полученным системой компьютерного зрения TurtleCV.

## Содержимое репозитория

- `turtle_cv.ipynb` — основной ноутбук проекта:
  - загрузка и знакомство с данными;
  - предобработка (пропуски, дубликаты, исправление ошибки ×10, выбросы);
  - разделение на train/val/test (60/20/20) без утечек;
  - обучение моделей: Dummy, LinearRegression, Lasso, Ridge, SGDRegressor;
  - сравнение на валидации, проверка лучшей модели на тесте;
  - оценка важности признаков, функция прогноза массы;
  - итоговые выводы и рекомендации.

## Что сделано

1. **Предобработка:** отфильтрован вид `Chelonia mydas`, удалены пропуски в `weight`, заполнены пропуски в `shell_crack`, удалены дубликаты, исправлена ошибка волонтёра (деление на 10 для аномально больших `shell_length` / `shell_width`), удалены нулевые `weight`.
2. **Моделирование:** обучены 5 типов моделей на 3 вариантах масштабирования (RAW, MinMax, Standard). Лучшая — Ridge(alpha=1.0) + новые признаки (`shell_area`, `flipper_area`, `shell_ratio`) на StandardScaler.
3. **Метрики лучшей модели:**
   - Validation: MAE 3.28 кг, RMSE 4.40 кг, MAPE 3.41%, R² 0.985
   - Test: MAE 3.34 кг, RMSE 4.59 кг, MAPE 3.37%, R² 0.982
4. **Важность признаков:** `shell_area` (31.4%), `flipper_area` (14.1%), `shell_width` (9.4%).
5. **Функция прогноза:** `predict_turtle_weight()` на основе коэффициентов Ridge и `StandardScaler`.
